# Expense-Tracker-project
This is an menu-driven expense tracker containing the following options in the main menu :
<img width="1651" height="132" alt="Screenshot (77)" src="https://github.com/user-attachments/assets/c7b05f87-6a40-402d-a497-bd91a7361737" />
You have to enter the number present before an option in order to use it.

**<h2>ADD</h2>**

This option allows the user to add records containing type, amount, category, date. At the end it asks wheather the user wants to enter more records. The user has to enter 'y' or 'Y' to enter more records else the user has to enter any other key from the keyboard, by doing so the main menu will appear again.
<img width="1605" height="655" alt="Screenshot (79)" src="https://github.com/user-attachments/assets/fdeb47bb-2b9d-46f7-85b3-a97b2f1daddb" />


  **NOTE :-**
        
        * For type other than 'income' (or 'INCOME') or 'expense' (or 'EXPENSE') ,record can not be added in a record.
        
        * If the date is not in proper DD/MM/YYYY format or if any slash(\) is missing, the record can not be added.

**<h2>EXIT</h2>**

You can see that the main menu appears again after performing that tasks of an option of the main menu, be this is because the program runs on an infinite loop. Hence you have to use the EXIT option of the main menu. By doing so, the infinite loop will break and u will have exit from the program.
